# Libiss POS — руководство по установке

Документ для владельца магазина и администратора торговой точки. Актуальные файлы установки всегда вынесены на страницу **https://pos.libiss.com/docs.html** (блок «Актуальные версии с облака») и в личном кабинете (**Обновления ПО**).

---

## 1. Как устроена система

- **Касса 1 (сервер)** — на этом компьютере работает локальный сервер (Node.js) и база **MySQL**. Сюда же ставится программа кассы или она ставится отдельным шагом того же установщика.
- **Кассы 2, 3, …** — только приложение POS (Windows или Android). Они подключаются к серверу по **локальной сети** (Wi‑Fi или кабель).
- **Облако (api.libiss.com)** — лицензия, справочники, обновления установочных файлов, синхронизация по мере настройки.

Без **MySQL** локальный сервер не запустится. Без **сервера** на кассе 1 остальные кассы не увидят данные магазина.

---

## 2. Что скачать

| Ситуация | Что брать |
|----------|-----------|
| Новый ПК под кассу 1, «всё с нуля» | Полный установщик (сервер + MySQL + касса) **или** связка из актуальных файлов по инструкции поддержки |
| MySQL уже установлен отдельно | Архив **сервера** (.zip) + установщик **Windows-кассы** (.exe) из облака |
| Вторая и следующие кассы Windows | Только **Windows** (.exe) POS |
| Касса на Android | Файл **Android** (.apk) |

Запасные ссылки на Google Drive на странице docs могут отставать по версии — ориентируйтесь на **облачные** кнопки загрузки.

## 3. Порядок установки (типичный сценарий)

1. Установите **MySQL** (если его ещё нет). Запомните пароль пользователя БД — он понадобится мастеру установки сервера.
2. Запустите **установщик кассы 1** и следуйте шагам на экране: компоненты сервера, БД, каталоги, ярлыки.
3. Убедитесь, что **сервис локального API** запущен (после установки обычно стартует автоматически).
4. Запустите **Libiss POS** на кассе 1. В настройках подключения к API укажите адрес вида `http://localhost:8080/api` (точный порт и путь смотрите в документации к вашей сборке или у поддержки).
5. Введите **ID магазина** и **ключ подписки** из личного кабинета на **pos.libiss.com** (раздел магазина / лицензии — как заведено у вас).
6. На **остальных кассах** установите только POS. В поле адреса сервера укажите **IP-адрес компьютера кассы 1** в вашей сети и тот же путь к API, например `http://192.168.0.15:8080/api`.

---

## 4. Сеть без отдельного роутера

Если нет Wi‑Fi роутера, на ПК кассы 1 можно включить **мобильный хот-спот Windows** (Параметры → Сеть и Интернет → Мобильный хот-спот). Остальные устройства подключаются к этой сети. В POS на них укажите IP этого ПК в подсети хот-спота (часто `192.168.137.1`; уточните через `ipconfig` или «Сведения» адаптера).

Проверьте **брандмауэр Windows**: должен быть разрешён входящий трафик на порт локального сервера.

---

## 5. Обновления после установки

- В **админке** (глобальный сервис) загружаются новые сборки по платформам. После публикации они сразу доступны как «последняя версия» на сайте и в API.
- Приложение POS при наличии интернета может **проверять обновления** и предлагать установку (Windows/Android). Полностью «тихая» переустановка без участия пользователя ОС обычно невозможна из соображений безопасности.
- **Локальный сервер** обновляется отдельно: скачивается новый архив `server_x.y.z.zip`, далее — сценарий обновления из инструкции к релизу или от поддержки.

## 6. Частые проблемы

| Проблема | Что проверить |
|----------|-----------------|
| Сервер не стартует | Установлен ли MySQL, верны ли хост/порт/логин/пароль БД в конфиге |
| Вторая касса не подключается | Одинаковая ли Wi‑Fi/подсеть, пингуется ли IP кассы 1, фаервол |
| «Неверный магазин / ключ» | ID и ключ из кабинета, нет ли пробелов при копировании |
| Сайт не показывает новую версию | Кнопка «Обновить ссылки» на docs; в админке опубликована ли платформа и активна ли запись |
| POS: «Нет подключения к локальному серверу» после установки | См. раздел **6.1** ниже |

## 6.1. Нет связи с локальным API сразу после `LibbisPOS_Setup.exe`

**Важно:** **`magazin_api.exe` не регистрируется как служба Windows** в `services.msc`. Это обычный процесс: скрытый запуск после установки / из автозагрузки (**`LibbisLocalAPI`** — если при установке была включена задача «Запускать API сервер при старте Windows»), либо запуск вручную. В меню «Пуск» в папке Libbis POS добавлен пункт **«Локальный API (консоль — отладка)»** — откроется окно с текстом ошибки, если процесс падает.

В **«Службах»** смотрите **MySQL** (например **`MySQL80`**). После установки инсталлятор теперь вызывает **`sc start`** и для уже установленного MySQL (раньше команда могла не выполняться).

1. **Диспетчер задач** — есть ли процесс **`magazin_api.exe`**. Если нет — сервер не запущен или сразу падает.
2. На **этом же ПК** в браузере откройте: **`http://127.0.0.1:8080/health`** — ожидается JSON с `"status":"ok"`. Если страница не открывается — Node не слушает порт (не запущен, другой порт, фаервол).
3. **Адрес в кассе:** на компьютере кассы 1 надёжнее **`http://127.0.0.1:8080/api`** или **`http://localhost:8080/api`**, а не IP другого устройства. `http://192.168.1.100:8080/api` имеет смысл только если **192.168.1.100 — реальный IP именно этого ПК** (`ipconfig`).
4. Логи: папка **`Documents\LibbisPOS\logs`**, рядом с сервером — **`setup_db.log`** (результат настройки БД при установке).
5. В старых сборках установщика шаг **`setupDatabase.exe`** мог **не запускаться**, если в комплекте уже лежали `config.json` и `secrets.enc` — тогда пароли в файлах не совпадали с вашим MySQL. В актуальном репозитории это исправлено (маркер **`.db_initialized`**). **Обход для уже установленной системы:** вручную запустите **`setup_db_hidden.vbs`** из папки `…\LibbisPOS\server\` (ПКМ → от имени администратора) или переустановите новым EXE после пересборки установщика.
