Отчёты склада

Суммы на складе приходят из локального POS уже в расшифрованном виде (как в вашей локальной базе).

Отчёты по кассирам

Периоды посчитаны на локальном сервере при последней отправке в облако. Свои даты — после следующей синхронизации с нужным периодом (настройка на сервере).

Свой период (например один день)
—

На локальном сервере: с 00:00 первой даты по 23:59 последней (часовой пояс компьютера с POS). После сохранения перезапустите локальный API с интернетом.
